# MiraXCode — Brand Guide

## Name

**MiraXCode** — written with capital **M**, **X**, and **C** (`MiraXCode` in prose; bundle name `MiraXcode` in Tauri).

- Repository: [miracuves/miraxcode](https://github.com/miracuves/miraxcode)
- Bundle identifier (do not change after ship): `com.miraxcode.app`
- Terminal / package: `miraxcode`

## Tagline

**Local-first AI workspace · Eleven modes · Zero telemetry**

## Voice

- Direct, technical, privacy-forward
- Emphasize: no product cloud, BYOK, OS keychain, open source
- Avoid implying we host models or store user data

## What MiraXCode is NOT

- Not a hosted AI service
- Not a fork of HashCortX marketing — this is the current product name
- Not a data collection product

## Legacy names

Older docs or paths may reference **HashCortX** / **HashCortx**. Treat those as deprecated; use **MiraXCode** in all user-facing text.
